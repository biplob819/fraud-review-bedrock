# E2.3 acceptance criteria

- **DSH-01:** `fraud evaluate` writes a summary that validates and round-trips; exit 1 on a leak; the v1 fixture stays byte-identical.
- **DSH-02:** the page has the safety, value, explanation, monitoring and run-facts panels and the simulated banner; no external URL or script.
- **DSH-03:** every number goes through the one formatter, which refuses a rate without n; the honesty gate fails if the label is removed.
- **DSH-04:** the workflow runs on main pushes only, with least-privilege permissions and the official Pages actions.
- **DSH-05:** `fraud report --example` renders offline from the golden run.
