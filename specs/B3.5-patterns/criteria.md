# B3.5 acceptance criteria

Each pattern has the problem, the pattern, where it lives, evidence from this project (labelled simulated) and its limits.

- **PAT-01:** policy as code and a router that decides, with the planted-clear test as evidence.
- **PAT-02:** a human-review queue with a hash-chained audit log, with the re-hashed-edit test as evidence.
- **PAT-03:** explanation checks, with the value-check shares as evidence; the faithfulness result is called a single-judge, partial, uncalibrated result.
- **PAT-04:** a cost model and spend cap, with the cap-is-a-total test as evidence; the earlier overrun is told truthfully.
