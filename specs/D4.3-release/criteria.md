# D4.3 acceptance criteria

- **OSS-01:** contributing, security (credential handling and how to report a vulnerability), code of conduct, issue and PR templates.
- **OSS-02:** a quickstart in order: the example report and the replay demo with no keys, then doctor, a dry run and the cap setting, then a run with your own credentials; every command named exists.
- **OSS-03:** guides for your own policy, your own alert data, cost control, and a privacy statement.
- **OSS-04:** a versioning policy, the changelog and a tag-triggered release workflow that builds the wheel and attaches it to a GitHub release; v0.1.0 is not tagged until the owner confirms; PyPI only on approval.
- **OSS-05:** a fresh-clone smoke job on Linux and macOS: clone, sync, version, example report.
- **OSS-06:** MIT licence, the Sparkov and Fraud Dataset Benchmark credit, and no data files tracked.
