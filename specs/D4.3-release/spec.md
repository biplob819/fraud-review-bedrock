# D4.3 — Open-source release

**Wave 4. Depends on:** E2.3, D4.1, B3.5.

## Goal
Everything a stranger needs to understand, run and trust the repository, ready to tag as v0.1.0 (D-26, D-32, D-41, D-44, D-45). Tagging and publishing wait for the owner's confirmation.

## Outputs
- Community files, issue and PR templates; a release README with screenshots, a step-by-step guide and links to every artifact; guides for your own policy, your own data, cost control and privacy; a versioning policy.
- `release.yml` (tag-triggered, least privilege, never publishes to PyPI) and `smoke.yml` (fresh clone on Linux and macOS); MIT licence and a data-credit notice with no data files tracked.

## Rules
- Nothing is tagged, released or published by this node. The owner confirms first.
- The README says the hosted demo is planned for v0.2 and that there is no video.
